# CSE341 Mini ATM System Project

A simulated ATM interface and control system designed for **CSE341: Microprocessor, Microcontrollers, and Interfacing**. This project demonstrates basic hardware interfacing, memory manipulation, and logic control to handle common automated teller machine operations.

---

## 📌 Features

* **User Authentication:** PIN verification with a limited number of failed attempts.
* **Account Operations:**
  * **Balance Inquiry:** Display current available funds.
  * **Cash Withdrawal:** Deduct valid amounts and check for insufficient funds.
  * **Cash Deposit:** Add funds to the current balance.
  * **PIN Change:** Update user access PIN securely.
* **Error Handling:** Input validation for invalid selections, incorrect PIN entries, and insufficient balance.

## 🚀 Getting Started

### Prerequisites
Make sure you have installed the appropriate compiler or simulator:
* [EMU8086 Microprocessor Emulator](https://emu8086-microprocessor-emulator.en.softonic.com/) (or equivalent x86 assembler)

### Running the Project

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/anishamahjabin/CSE341_project_MiniATM.git](https://github.com/anishamahjabin/CSE341_project_MiniATM.git)
   cd CSE341_project_MiniATM

```

2. **Open in Emulator:**
* Open EMU8086 (or your specified IDE).
* Load the main source file (`.asm` or `.c`).
* Click **Compile** and then **Run / Emulate**.

## 🎮 How to Use

1. Run the simulation.
2. Enter the default PIN (e.g., `1234`).
3. Select an option from the menu:
* `1` - Check Balance
* `2` - Deposit Cash
* `3` - Withdraw Cash
* `4` - Change PIN
* `5` - Exit


4. Follow the on-screen prompts to complete transactions.
